# RustPlayGround

A small Rust playground for learning core concepts such as `for` loops, vectors, functions, and basic control flow.

## What is included

This project contains a minimal Cargo project with a few example functions that help you practice:

- `for` loops
- `Vec<T>` collections
- if conditions and filtering
- function decomposition
- iteration patterns

## Example exercises

Each of the following ideas can be added to this project as a new function or a new example block:

1. Create a function that prints every odd number from 1 to 25.
2. Write a `while` loop that counts down from 10 to 1.
3. Build a `Vec<&str>` of names and print each one with a `for` loop.
4. Add a function that calculates the average of a list of numbers.
5. Explain in comments which concept is being practiced in each example.

## Run it

```bash
cargo run
```

## Run the tests

```bash
cargo test
```

## Concepts being learned here

- loops and iteration
- ranges and indexing
- collecting values into a vector
- using conditions inside loops
- writing small, testable Rust functions
